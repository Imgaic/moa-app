# 임시 결정, 가정, 물어볼 것

구현을 이어가면서 생긴 임시 결정과 가정, 디자이너와 백엔드에게 물어볼 것을 여기에 쌓는다.
기획, 디자인, 데이터 스키마는 모두 확정 전이다. 이 문서의 내용은 규칙이 아니라 "지금은 이렇게 해 두었다"는 기록이다.

- 흐름의 기준은 `docs/user-flow.md`다. 이 문서와 어긋나면 날짜가 더 늦은 쪽이 맞다.
- 디자인의 기준은 피그마 `최종UI` 프레임이다.

## 2. 구현하면서 둔 가정

(작업마다 추가한다. 형식: 날짜, 어느 PR, 무엇을 가정했는지)

- 2026-11-17, #9: 소셜 버튼 글자색 `#14181F`가 팔레트에 없어 `gray-60`을 썼다.
- 2026-11-17, #9: 버튼 라벨은 스타일이 Body1/Bold인데 글꼴 값은 Regular로 조회된다. Bold로 구현했다.
- 2026-11-18, feat/ui-primitives-2: 사진이 없는 아바타는 이름 뒤 두 글자를 보여준다(T7). 이름이 한 글자면 한 글자, 비어 있으면 글자 없이 회색 원만 둔다. 앞뒤 공백은 지우고, 영문 이름도 같은 규칙(뒤 두 글자)이다.
- 2026-11-18, feat/ui-primitives-2: 이름 글자 크기는 피그마 Avatar(지름 186, 글자 80)의 비율을 다른 크기(64, 128, 44)에도 그대로 썼다. 피그마에는 Member, Group, Map Pin의 이름 글자형이 없다. 토큰에 없는 크기라 글자 크기만 style로 넣었다.
- 2026-11-18, feat/ui-primitives-2: Avatar/Member의 이름과 상태 글자는 피그마 코드상 Regular라 Regular로 했다(스타일 목록에는 Caption/Bold 12도 보인다). Badge/Progress의 글자도 같은 이유로 Regular다.
- 2026-11-18, feat/ui-primitives-2: Avatar/Map Pin의 짙은 테두리는 피그마에서 사진 이미지 안에 들어 있다. 코드에서는 gray-60 2px 테두리로 그렸다.
- 2026-11-18, feat/ui-primitives-2: Top Bar의 Large Title은 피그마에서 "약속" 글자가 바(높이 95) 아래로 넘친다. 코드에서는 바가 글자를 덮도록 길어진다(상태 표시줄 아래 43.5).
- 2026-11-18, feat/ui-primitives-2: Tab Bar는 피그마 높이 84를 "아이콘 줄 50 + 홈 인디케이터 34"로 보고, 아래 여백을 safe area로 바꿨다. 홈 인디케이터가 없는 기기에서는 50이 된다.
- 2026-11-18, feat/ui-primitives-2: 채운 사람 아이콘(Tab Item User Active)은 피그마 원본이 빈 사람보다 (0.53, 0.5) 어긋나 있어 빈 사람 위치에 맞췄다. 채운 달력도 피그마 원본의 1.08 가로 어긋남을 맞췄다.
- 2026-11-18, feat/ui-primitives-2: 카메라 아이콘의 렌즈는 피그마에서 흰색으로 채워져 있지만 몸통이 비어 있어 흰 바탕에서는 차이가 없다. 글자색 하나로 칠하려고 비워 두었다. 카메라 버튼 안의 아이콘은 gray-10 한 색이다(피그마는 몸통 gray-10, 렌즈 흰색).
- 2026-11-18, feat/ui-primitives-2: Tooltip/Recent는 피그마에서 너비 92 고정이다. 글자를 props로 받으니 글자 너비에 맞추고, 같은 너비가 나오게 좌우 여백 11을 두었다.
- 2026-11-18, feat/ui-primitives-2: 상태 변화 애니메이션은 토글 200ms, 입력 칸 포커스 밑줄 200ms, 탭 선택 180ms, 입력 완료 체크 180ms 페이드다. 곡선은 ease-out이다. iOS의 "동작 줄이기"가 켜져 있으면 애니메이션 없이 바로 바뀐다(reanimated의 ReduceMotion.System).

## 3. 디자이너에게 물어볼 것

- 소셜 버튼 글자색 `#14181F`를 팔레트에 넣을지
- 투표가 동률일 때의 표시
- Top Bar Large Title의 제목이 바 아래로 넘치는 것이 의도인지(코드는 바를 늘렸다)
- Avatar/Member, Group, Map Pin에 사진이 없을 때(이름 글자형)의 디자인. 지금은 Avatar(186)의 글자 비율과 회색 바탕을 그대로 썼다
- Avatar/Member와 Badge/Progress 글자가 Regular인지 Bold인지(스타일 목록에 Caption/Bold가 함께 보인다)
- Tab Item의 채운 사람, 채운 달력 아이콘이 빈 아이콘과 위치가 조금 어긋난 것이 의도인지
- Tooltip/Recent의 꼬리 위치(오른쪽에서 19)가 가리키는 대상. 글자가 바뀌어도 오른쪽 기준이 맞는지
- 상태 변화 애니메이션의 시간과 곡선(피그마에 없음)
